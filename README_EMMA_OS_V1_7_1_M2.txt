Emma OS v1.7.1 — Finanzas M2

Esta versión avanza la migración de Control Financiero Personal a la etapa M2:
- FinanceRepository
- GoogleSheetsFinanceAdapter
- FinanceService
- Backend Apps Script de referencia
- Pruebas locales de repositorio

La Google Sheet financiera sigue siendo la fuente de verdad inicial.
La Web App estable v1.0 / snapshot v10.1-auditoria queda como fallback.

Instalación:
1. Exportar respaldo global de Emma OS.
2. Subir el contenido del ZIP a la raíz del repo GitHub Pages.
3. Commit sugerido: Actualizar Emma OS a v1.7.1 Finanzas M2
4. Abrir con ?v=1.7.1
5. Entrar a Finanzas.
6. Ejecutar pruebas M1 y M2.
7. Configurar Apps Script M2 si se quiere probar lectura desde Sheets.

Importante: no subir URL real ni clave privada al repo público.
