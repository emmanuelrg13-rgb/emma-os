Configurar adaptador Google Sheets

Usa una implementación nueva de Apps Script apuntando a la misma Google Sheet de Control Financiero. Pega el script M2, define el ID de la planilla y una clave privada, despliega como Web App y guarda aquí la URL /exec.

La configuración queda sólo en localStorage de este dispositivo. No se sube al repositorio público.

Alcance seguro de M2

No registra pagos reales, no anula pagos, no crea ítems y no archiva ítems desde Emma OS. M2 prueba la frontera de persistencia: leer desde Google Sheets y comparar resultados livianos contra FinanceCore.
