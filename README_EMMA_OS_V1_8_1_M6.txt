Emma OS v1.8.1 — M6 ajustes visuales web
=========================================

Contenido:
- Portada actualizada a v1.8.1.
- Pendientes con mejor distribución en navegador.
- Rutina con botón para actualizar la semana visible a la actual.
- Finanzas con interfaz limpiada para uso diario.
- Service worker con nuevo cache para evitar que el navegador conserve archivos viejos.

Sugerencia de publicación:
1. Haz un respaldo desde el módulo de Respaldos.
2. Sube el contenido completo de esta carpeta al repositorio de GitHub Pages.
3. Espera a que GitHub publique la nueva versión.
4. Abre Emma OS y, si el navegador conserva caché, recarga fuerte una vez.
5. Revisa Pendientes, Rutina y Finanzas en escritorio.
6. Luego valida en móvil si quieres decidir si hace falta una M7.
