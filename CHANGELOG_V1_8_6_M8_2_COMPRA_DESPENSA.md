# Emma OS v1.8.6 — M8.2 Compra desde lista

## Despensa

- Se añadió casilla de verificación por cada ítem de la lista de supermercado.
- Se añadió contador de cantidad comprada por ítem.
- Se añadió botón **Guardar compra** para actualizar stock local según los envases comprados.
- Se añadió `purchaseLog` como historial simple de compras guardadas.
- La lista ahora ordena productos urgentes antes que normales.
- Se añadió botón **Subir respaldo actualizado a Sheets** desde Despensa.

## Sync Sheets

- Se mantiene el flujo de respaldo global de Emma OS.
- Despensa ahora puede disparar la subida del respaldo global usando la configuración ya guardada de Sync Sheets.

- No se toca la Google Sheet original de despensa.
