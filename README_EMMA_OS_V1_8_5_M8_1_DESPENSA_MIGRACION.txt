Emma OS v1.8.5 — M8.1 Despensa migración inventario original
=================================================================

Esta versión mantiene Despensa simple. pero agrega una forma directa de cargar el inventario original desde el Excel exportado.

Pasos de uso:
1. Publica esta versión en GitHub Pages.
2. Abre Emma OS con ?v=1.8.5.
3. Entra a Despensa.
4. Pulsa “Cargar inventario original”.
5. Confirma la carga.
6. Revisa Inventario. Faltantes y Lista.

Resultado esperado:
- 36 productos activos.
- 6 agotados.
- 2 bajo mínimo.
- 16 ítems sugeridos para la lista.
- Total estimado inicial: $27.340 CLP.

Importante:
La carga reemplaza la despensa local actual en ese navegador.
Exporta JSON antes si tienes datos manuales que quieras conservar.
