Emma OS v1.8.2 — M7
====================

Cambios principales:
- Rutina atómica: tarjetas de avance con contraste corregido.
- Pendientes diarios: grupos reutilizables, nuevo grupo desde formulario y fecha objetivo al crear tareas.
- Sync Sheets: nuevo Apps Script v1.8.2, diagnóstico de subida y subida por partes con confirmación.

Publicación sugerida:
1. Exporta respaldo global manual antes de subir cambios.
2. Sube el contenido completo del ZIP al repositorio de GitHub Pages.
3. Abre Emma OS con ?v=1.8.2.
4. Revisa Rutina, Pendientes y Sync Sheets.
5. Para Sync Sheets, copia el Apps Script v1.8.2 desde el módulo, reemplaza el anterior, guarda y publica nueva versión /exec.
6. Ejecuta: Probar conexión > Diagnóstico Sheets > Subir respaldo a Sheets.
