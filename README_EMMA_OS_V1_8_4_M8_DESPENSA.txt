Emma OS v1.8.4 — M8 Despensa simple
===================================

Esta versión añade el módulo Despensa como módulo nativo simplificado de Emma OS.

Publicación sugerida:
1. Exportar respaldo global desde Emma OS actual.
2. Subir todo el contenido de este paquete a la raíz del repo GitHub Pages.
3. Commit sugerido: Actualizar Emma OS a v1.8.4 M8 Despensa simple
4. Abrir con ?v=1.8.4 para evitar caché.
5. Entrar a Despensa y probar: cargar ejemplo, añadir producto, editar stock, validar faltantes y generar lista.
6. Revisar Respaldos y Sync Sheets para confirmar que Despensa aparece como módulo.

Nota:
El Apps Script de Sync Sheets v1.8.3 debería seguir funcionando porque la lista de módulos se envía desde Emma OS. Se incluye Apps Script v1.8.4 para mantener etiquetas/versiones alineadas si se desea actualizar.
